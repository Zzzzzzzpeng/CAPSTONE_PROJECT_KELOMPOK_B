WHO ARE WE?

Bukan sekadar halaman.

Kelompok B membangun sistem yang terhubung.

Sumber Aquarium PGK dibuat sebagai aplikasi web internal untuk membantu operasional toko ikan hias dalam mengelola inventaris dan aktivitas transaksi.

Data ikan, stok, harga, transaksi penjualan, pencatatan kematian, riwayat operasional, dashboard, dan autentikasi CEO ditempatkan dalam satu alur sistem.

01
Data lebih terpusat Data operasional disimpan pada PostgreSQL sebagai database utama.
02
Operasional lebih terstruktur Stok, penjualan, dan pencatatan kematian memiliki alur masing-masing.
03
Backend menangani logika Validasi, transaksi database, authentication, dan API ditangani server Flask.
04
Sistem siap dijalankan Aplikasi dapat dijalankan menggunakan Gunicorn untuk deployment.

WHY WE BUILD THIS

Masalahnya sederhana. Sistemnya harus jelas.

Masalah

Operasional toko membutuhkan data yang teratur.

Pengelolaan ikan tidak hanya membutuhkan daftar stok. Ada data jumlah ikan, harga, transaksi, perubahan stok, kematian ikan, serta riwayat aktivitas yang harus tetap terhubung.

Solusi

Satu sistem untuk seluruh alur utama.

Sumber Aquarium PGK menggabungkan frontend, backend, database, authentication, dan API sehingga data operasional memiliki alur yang lebih terstruktur.

Manajemen stok ikan
Pencatatan penjualan
Pencatatan kematian
Riwayat operasional
Autentikasi CEO
