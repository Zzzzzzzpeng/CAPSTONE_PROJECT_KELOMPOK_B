Sistem informasi operasional

Sumber Aquarium PGK menghubungkan data persediaan ikan dengan proses penjualan dan pencatatan kematian. Backend Flask berkomunikasi dengan PostgreSQL melalui Psycopg.

🐟
Manajemen stokTambah, lihat, cari, dan hapus data ikan.
🛒
PenjualanTransaksi mengurangi stok dan menyimpan histori.
⚠️
MortalitasKematian mengurangi stok dan disimpan dalam histori.
🔐
AuthenticationSession digunakan untuk melindungi endpoint operasional.

Source code, database schema, seed data, documentation, presentation, dan assets project berada dalam repository kelompok.
